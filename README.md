# ✨ CSS Animation Gallery

เว็บแกลเลอรีรวมแอนิเมชัน CSS สวย ๆ **59 แบบ** พร้อมตัวอย่างสด ชื่อเรียก และโค้ดที่คัดลอกไปใช้ได้ทันที
สร้างด้วย **HTML + CSS + JavaScript ล้วน ๆ** (Vanilla) ไม่ต้องติดตั้งไลบรารีใด ๆ เพิ่ม

## 🚀 วิธีใช้งาน

**วิธีที่ 1** — เปิดไฟล์ `index.html` ตรง ๆ ในเบราว์เซอร์ ก็ใช้ได้เลย

**วิธีที่ 2** — รันผ่านเซิร์ฟเวอร์ local:

```bash
python3 -m http.server 8080
# แล้วเปิด http://localhost:8080
```

## 🎨 คุณสมบัติ

- **59 แอนิเมชัน** แบ่งเป็น 6 หมวด: ตัวโหลด (18) / ข้อความ (10) / ปุ่ม (9) / องค์ประกอบ (10) / สามมิติ (4) / พื้นหลัง (8)
- ดู **ตัวอย่างสด** ทุกใบ + ปุ่มเล่นซ้ำ (รายการแบบ hover จะมีป้าย "Hover ชี้เมาส์")
- ปุ่ม **คัดลอกทั้งหมด** (HTML + CSS พร้อมคอมเมนต์) หรือเลือกคัดลอกเฉพาะ HTML / CSS
- **ค้นหา** ได้ทั้งชื่ออังกฤษและไทย (กด `/` เพื่อโฟกัสช่องค้นหา)
- **กรองตามหมวดหมู่** พร้อมตัวเลขนับ
- ธีม **Glassmorphism** สีสันสดใส สลับโหมด **มืด / สว่าง** ได้ (จำค่าไว้ใน localStorage)
- โค้ดในแต่ละใบ **พึ่งตัวเองได้ 100%** — class และ keyframes ไม่ชนกัน ก๊อปแปะคือใช้ได้

## 📁 โครงสร้างไฟล์

```
css-animation-gallery/
├── index.html      # โครงหน้าเว็บ
├── css/
│   └── style.css   # สไตล์เว็บ (ธีม glass, การ์ด, โค้ด)
├── js/
│   ├── data.js     # ข้อมูลแอนิเมชันทั้ง 59 แบบ (เพิ่มแอนิเมชันใหม่ที่นี่)
│   └── app.js      # เรนเดอร์ / ค้นหา / กรอง / copy / ธีม
└── README.md
```

## ➕ การเพิ่มแอนิเมชันใหม่

เปิดไฟล์ `js/data.js` แล้วเพิ่มออบเจ็กต์ใหม่ในอาร์เรย์ `ANIMATIONS`:

```js
{
  id: 'my-anim',            // ชื่อ id ต้องไม่ซ้ำ
  name: 'My Animation',     // ชื่ออังกฤษ
  th: 'แอนิเมชันของฉัน',    // ชื่อไทย
  cat: 'element',           // loading | text | button | element | three | bg
  hint: 'hover',            // (ไม่บังคับ) ใส่ถ้าต้องชี้เมาส์เพื่อดูเอฟเฟกต์
  html: `<div class="my-anim"></div>`,
  css: `.my-anim { ... }`
}
```

รีเฟรชหน้าเว็บ การ์ดใหม่จะโผล่ทันที พร้อมตัวเลขนับที่ชิปหมวดหมู่อัปเดตให้เอง
